# Emotion Detector Project

## Project Description

Emotion Detector is an AI-based web application that analyzes text and identifies the emotions expressed in it.

The application uses the Watson NLP library to detect five emotions:

* Anger
* Disgust
* Fear
* Joy
* Sadness

It also identifies the **dominant emotion** expressed in the given text.

## Technologies Used

* Python
* Watson NLP
* Flask
* Unit Testing
* Pylint

## Project Features

* Detects emotions from text
* Identifies the dominant emotion
* Provides formatted emotion scores
* Includes unit testing
* Provides a Flask-based web interface
* Includes error handling
* Supports static code analysis
